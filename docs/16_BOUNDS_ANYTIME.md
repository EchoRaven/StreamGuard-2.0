# 16 · 风险上界与 anytime-valid 监控

落实 `docs/15 §6` 的两条待办。出处 Kotte 2026 (arXiv:2606.29054)。

## 1. 四个界的对比 —— 精确二项在稀缺区间大幅胜出

原文证明的层级是 **Hoeffding ⊆ Bernstein ⊆ e-CRC**（α ≤ 0.20），
最小充分集 {Hoeffding, e-CRC}。

**但原文没有列精确二项（Clopper-Pearson）**，而那正是我们在用的。
我们的漏报损失是 **0/1**，精确二项对伯努利是**紧的**。

### n = 45，零漏报，目标 α = 0.05

| 界 | UCB | 认证? |
| --- | --- | --- |
| Hoeffding | 0.1824 | ✗ |
| Bernstein | 0.1589 | ✗ |
| e-CRC | — | ✗ |
| **精确二项** | **0.0499** | **✓** |

**只有精确二项能认证。** 这也正是 `docs/03 §2.4` 里 45 这个数的来源：
`exact_binomial_ucb(zeros(45)) ≤ 0.05` 而 `n=44` 就超了。

### 认证 α=0.05 所需的最小 n（真实漏报率 2%）

| 界 | 最小 n |
| --- | --- |
| Hoeffding | 1657 |
| Bernstein | 466 |
| e-CRC | 265 |
| **精确二项** | **105** |

**差一个数量级。** 这对我们特别要紧：`docs/13` 实测流式训练下正例
**极度稀缺**（6322 个 tick 里只有 58 个正例），能用 105 而不是 1657
个校准正例，直接决定这条路走不走得通。

⚠️ 精确二项**只对 0/1 损失有效**。风险非二值时 `exact_binomial_ucb()`
自动退回 Hoeffding —— 硬套会给出**无效**的界。

## 2. Anytime-valid 监控:跨域漂移下替代 ACI

### 为什么 ACI 在这里不行

> **Proposition 8（emit-only feedback obstruction）**
> 只在被放行的样本上观测风险时，任意保证 anytime emitted-risk 控制的
> 方法都能被构造出违反。**ACI 正是 emit-only。**

正面保证需要 **full feedback** —— 在我们这里就是**随机审计采样**。

### 实测对照

同一条流，风险从 2% 漂到 40%（目标 α=5%）：

| | 结果 |
| --- | --- |
| Prop.3 弃权下界 | 36.8% |
| **ACI** | 经验风险 **20.2%**（目标 5%），偏差 0.152 —— **控不住** |
| **Monitor** | 弃权率 **100%**，认证阈值全部撤销 —— 达到下界 |

可行区间下（µ=2% < α=5%）monitor 并不平凡：弃权率 **0.4%**，7 个阈值
全部认证。

### ★ 实现时抓到的关键 bug:认证必须可撤销

初版的上鞅**只涨不跌**，于是阈值一旦认证就**永久认证**。
漂移后不会收回，实测弃权率只有 **3.8%**，远低于 36.8% 的下界
——**保证是假的，而且不报任何错**。

修法两处：

1. **财富从峰值跌破 `revoke_ratio` 即撤销认证**，并重开一局
   （不带着旧财富，否则旧证据会继续支撑已被推翻的认证）
2. **下注用近期窗口而非全历史** —— 用全历史的话，漂移前积累的低风险
   会一直把下注拉高，监控对新风险反应迟钝

## 3. 三个机制的分工

| 机制 | 适用 | 代价 |
| --- | --- | --- |
| **静态 conformal**（精确二项） | 每个 epoch 的操作点 | 需 ≥45 校准正例 |
| **ACI** | epoch 内的**时序漂移** | 仅 emit-only，跨域失效 |
| **Anytime monitor** | **跨域 / 换政策** | 需 full feedback（审计），弃权更多 |

三者不是三选一：静态给操作点，ACI 管流内漂移，monitor 管换域。
换域时**先查可行性**（`abstention_floor`），不可行就别指望调参。
